# prog

A personal Claude Code plugin for keeping repos navigable across long breaks: one home per question, temporary plans in `.plans/`, the *why* in commit bodies, and a mechanical docs check.

## Install

```
/plugin install prog --marketplace viennamccarthy/prog
```

Needs [Bun](https://bun.sh) on the PATH.

## Docs

Docs live in `docs/` at each doc root, holding only the subfolders that root needs (`wiki/`, `decisions/`, `learning/`, `reference/`).
